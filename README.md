# brain-starter

The folder structure + skills you need to give your AI a memory.

Set up in 1 hour. No coding. No terminal.

---

## What this is

A scaffold for a personal second brain — a folder you point Claude at, and it becomes the memory layer for your work. Meetings, articles, decisions, people, projects — all of it linked, searchable in plain English, and sourced.

Designed for non-technical users. If you've used ChatGPT/Notion/Obsidian and felt the limits, this is the next step.

## How to use

1. Download this folder (Code → Download ZIP, or clone).
2. Unzip onto your Desktop.
3. Open `START-HERE.md` and follow the steps.

You'll need 2 free apps: [Claude Code Desktop](https://claude.com/claude-code/download) and [Obsidian](https://obsidian.md/download).

## What's in here

- **`START-HERE.md`** — the setup flow. Start here.
- **`STARTER-PROMPT.md`** — copy-paste prompt for your first conversation with Claude.
- **`_system/`** — schema + rules + your customization. Set up once, mostly forget.
- **`raw/`** — where you drop your input (meetings, articles, voice memos). Claude reads, never modifies.
- **`wiki/`** — where Claude writes the structured knowledge. You read, ask, curate.
- **`_outputs/`** — drafts before they go to `wiki/`. You approve, Claude commits.
- **`.claude/skills/`** — Claude's tools (ingest, lint, link). You don't touch these directly.

## What it's not

- Not a SaaS product. It's a folder. You own it forever.
- Not a chat-history saver. Claude builds structured pages with citations, not a transcript log.
- Not a notes app replacement. It complements Obsidian/Notion — drop your existing notes in and Claude indexes them.
